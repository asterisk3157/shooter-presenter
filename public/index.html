PDFのスライドを、ブラウザだけで発表

または、この画面にPDFをドラッグ

  • 開いたファイルは、このブラウザの中だけで表示します。外部には送信しません
  • PowerPoint・Keynote・Googleスライドの資料は、PDFに書き出してから開きます
動く幅 ±25°
→ / Space: 次へ　←: 前へ　F: 全画面　P: 点を出す・消す　引き金を短く: 次へ　長押し: 前へ　C: 照準を中央に　X / Y: 向きを反転

PDFに書き出してから開きます

このビューアが開けるのはPDFです。元の資料を作ったアプリで、PDFに書き出してください。

PowerPointファイル → エクスポート → PDF
Keynoteファイル → 書き出す → PDF
Googleスライドファイル → ダウンロード → PDFドキュメント

アニメーションと動画は、PDFでは動きません。
