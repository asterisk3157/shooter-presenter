# Shooter Presenter

PDFのスライドを、ブラウザだけで発表できるビューアです。C4'sのシューター（銃型コントローラー）を接続すると、レーザーポインターとして使えます。

**公開URL**: https://shooter-presenter.pages.dev/

## 特徴

- PDFを選ぶだけで、スライドとして全画面で映せる
- 開いたファイルは、ブラウザの中だけで表示する。外部には送信しない
- キーボード、マウス、スマホのタップでページを送れる
- シューターを向けた所に点が出る。引き金でページを送れる

## 使い方

1. 公開URLを開く
2. 「PDFを選ぶ」を押すか、画面にPDFをドラッグする
3. `F` キーで全画面にする

PowerPoint・Keynote・Googleスライドの資料は、PDFに書き出してから開きます。アニメーションと動画は動きません。

| アプリ | 書き出し方 |
|---|---|
| PowerPoint | ファイル → エクスポート → PDF |
| Keynote | ファイル → 書き出す → PDF |
| Googleスライド | ファイル → ダウンロード → PDFドキュメント |

## 操作

| 操作 | 動き |
|---|---|
| `→` / `Space` / `Enter` | 次のページ |
| `←` / `Backspace` | 前のページ |
| `Home` / `End` | 最初・最後のページ |
| `F` | 全画面 |
| `P` | 点を出す・消す |
| 画面の右側をタップ | 次のページ |
| 画面の左側（3分の1）をタップ | 前のページ |
| 画面の上の端をタップ | メニューを出す |

「マウスをポインターにする」を押すと、マウスの位置に点が出ます。クリックで次のページ、長押しして離すと前のページです。

## シューターをつなぐ

パソコン版のChromeかEdgeで使えます（Web Serialを使うため）。

1. シューターをUSBでつなぐ
2. 「シューターを接続」を押して、一覧からシューターを選ぶ
3. つながったとき向けていた方向が、画面の中央になる

| 操作 | 動き |
|---|---|
| 引き金を短く引く | 次のページ |
| 引き金を0.6秒より長く引いて離す | 前のページ |
| リセットボタン / `C` | 照準を中央に戻す |
| `X` / `Y` | 左右・上下の向きを反転する（ブラウザが覚える） |
| 「動く幅」 | 画面の端まで動かすのに必要な角度を変える |

2026年版のプログラムを書きこんだシューターに対応しています。2025年版のプログラムのままでも、点の移動と「次のページ」だけは動く作りにしていますが、実機では確かめていません。

## 手元で動かす

```bash
python3 -m http.server 8771 --directory public
```

`http://localhost:8771` を開きます。ファイルを直接開く（`file://`）と、PDFの表示とシューターの接続が動きません。
